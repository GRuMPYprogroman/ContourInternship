# ContourInternship

WPF-приложение для обработки бинарных файлов `.dat` и выгрузки результатов в `.csv`.
Проект сделан как тестовое задание: пользователь выбирает входной файл данных и путь
для результата, запускает обработку одного из двух модулей и получает CSV-файл с
расшифрованными значениями.

## Возможности

- две независимые вкладки для обработки данных Module 1 и Module 2;
- выбор входного `.dat` и выходного `.csv` через диалог открытия файла;
- валидация расширений файлов прямо в интерфейсе;
- блокировка повторного запуска обработки, пока текущая задача выполняется;
- отображение прогресса обработки;
- сохранение последних выбранных путей между запусками приложения.

## Технологии

- C#;
- .NET 9;
- WPF;
- MVVM;
- CommunityToolkit.Mvvm.

## Требования

- Windows;
- установленный .NET SDK 9.x;
- установленный Windows Desktop Runtime 9.x, если приложение запускается без SDK.

Проверить установленный SDK можно командой:

```powershell
dotnet --info
```

## Запуск

Из папки `WpfApp`:

```powershell
dotnet run --project .\WpfApp\WpfApp.csproj
```

Сборка решения:

```powershell
dotnet build .\WpfApp.sln
```

## Использование

1. Откройте приложение.
2. Перейдите на вкладку нужного модуля: `Module 1` или `Module 2`.
3. В поле `DataFile` выберите входной файл `.dat`.
4. В поле `CsvFile` выберите или укажите файл результата `.csv`.
5. Нажмите `Start Process`.
6. После завершения обработки результат будет записан в выбранный CSV-файл.

Если путь пустой или выбран файл с неверным расширением, поле подсвечивается красным,
а кнопка запуска остается недоступной.

## Формат обработки

### Module 1

Module 1 читает бинарный файл пакетами по 1456 байт:

- `Size` - 4 байта;
- `Type` - 4 байта;
- `Number` - 4 байта;
- `TimeMs` - 4 байта;
- блок из 60 строк по 6 каналов, каждое значение канала хранится как `int32`.

Для каждого пакета приложение считает среднее значение по каждому из 6 каналов и
записывает строку в CSV:

```csv
Packet;Channel 1;Channel 2;Channel 3;Channel 4;Channel 5;Channel 6
```

Если размер файла не кратен 1456 байтам, обработка прерывается с сообщением об ошибке.

### Module 2

Module 2 проверяет, что размер файла кратен 32 байтам, читает данные блоками и
раскладывает 32-битное значение по битовым полям:

- `IsEnabled1` - бит 0;
- `Value11` - биты 1-3;
- `Value12` - биты 4-6;
- `Value13` - биты 7-15;
- `IsEnabled2` - бит 16;
- `Value21` - биты 17-27;
- `Value22` - биты 28-31.

Результат записывается в CSV:

```csv
IsEnabled1;Value11;Value12;Value13;IsEnabled2;Value21;Value22
```

Если размер файла не кратен 32 байтам, обработка прерывается с сообщением об ошибке.

## Хранение настроек

Последние выбранные пути сохраняются в файле:

```text
%APPDATA%\WpfContourApp\PathData\cache.bin
```

Файл создается автоматически при закрытии приложения.
